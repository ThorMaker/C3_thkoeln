# Aufgabenkarte K: Ein Team-Repository aufsetzen

**Ziel:** gemeinsamen Kontext für mehrere Claude-Instanzen schaffen. **Dauer:** 20 Minuten. **Ausführlich:** Skript, Kapitel 6.

1. `zusammenarbeit/team-repo-vorlage/` in einen neuen Ordner kopieren, `git init`.
2. Claude die `CLAUDE.md` an Ihr Projekt anpassen lassen.
3. Mit dem Skill `entscheidung-dokumentieren` einen ersten ADR anlegen.
4. Optional: Repository auf GitHub oder dem GitLab der Hochschule teilen und eine zweite Person mit ihrer Claude-Instanz dieselbe Frage stellen lassen.
