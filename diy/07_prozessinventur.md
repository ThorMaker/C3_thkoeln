# Aufgabenkarte I: Prozessinventur

**Ziel:** die drei besten Automatisierungskandidaten Ihres Alltags finden. **Dauer:** 20 Minuten. **Ausführlich:** Skript, Kapitel 8.3.

1. In Claude Code eingeben: `/prozessinventur`
2. Zehn wiederkehrende Aufgaben nennen und die Fragen beantworten.
3. Tabelle prüfen, sortierte Auswertung ansehen.
4. Für den besten Kandidaten eine prüfbare Erfolgsbedingung formulieren.

Ohne Claude: `vorlagen/prozessinventur.csv` ausfüllen und `python3 tools/prozessinventur.py vorlagen/prozessinventur.csv` ausführen.
