# Aufgabenkarte A: Claude Code in 10 Minuten

**Ziel:** Claude Code starten und erleben, wie Claude selbst Dateien öffnet.
**Dauer:** 5 bis 10 Minuten. **Ausführlich:** Skript, Kapitel 3.2.

## Schritte
1. Repository als ZIP herunterladen und entpacken.
2. Claude Desktop öffnen, Tab **Code**.
3. Umgebung **Local**, Projektordner `claude-hochschule-2026`, Modus **Manual**.
4. Eingeben: `Erkläre mir dieses Repository in fünf Sätzen. Ändere nichts.`
5. Nachfragen: `Welche Übung passt zu mir als Einsteigerin oder Einsteiger, und warum?`
6. Lernkontrolle: `/skript-tutor Prüfe mein Verständnis von Kapitel 1 mit drei Fragen.`

## Beobachten
Welche Dateien öffnet Claude? Tipp: Transkript-Ansicht auf „Verbose“ stellen.

## Ohne Claude Desktop (Kommandozeile)
```bash
# macOS, Linux
curl -fsSL https://claude.ai/install.sh | bash
# Windows PowerShell
irm https://claude.ai/install.ps1 | iex
# dann im Ordner des Repositorys
claude
```
