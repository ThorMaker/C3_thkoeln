# Aufgabenkarte H: Einen Wissensgraphen bauen

**Ziel:** aus verknüpften Notizen einen abfragbaren Graphen machen. **Dauer:** 20 Minuten. **Ausführlich:** Skript, Kapitel 5, und `second-brain-demo/README.md`.

1. `uv tool install graphifyy` und `graphify install`.
2. In Claude Code: `/graphify second-brain-demo/unterlagen`.
3. `graph.html` öffnen, `GRAPH_REPORT.md` lesen.
4. Fragen: `/graphify path "Zettelkasten" "KI-Richtlinie"`.
5. Transfer: dasselbe mit einem eigenen Ordner mit unkritischen Unterlagen (Ampel grün).
