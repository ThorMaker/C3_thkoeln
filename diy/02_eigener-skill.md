# Aufgabenkarte B: Ihr erster Skill in 15 Minuten

**Ziel:** eine wiederkehrende Aufgabe als Skill festhalten und testen.
**Dauer:** 10 bis 15 Minuten. **Ausführlich:** Skript, Kapitel 3.3.

## Schritte
1. **Aufgabe wählen:** etwas, das Sie regelmäßig tun und das einem Muster folgt.
2. **Anlegen lassen** (Beispiel anpassen):
   ```text
   Lege einen Projekt-Skill namens "mail-dekanat" an. Er soll aus meinen
   Stichpunkten eine sachliche E-Mail an das Dekanat formulieren.
   Fehlende Angaben (Anlass, Frist) soll er nachfragen.
   Zeige mir die SKILL.md, bevor du sie speicherst.
   ```
3. **Prüfen:** Sagt die Beschreibung im Kopfbereich klar, wann der Skill gebraucht wird?
4. **Testen** in einer neuen Sitzung:
   ```text
   /mail-dekanat Raumwechsel Seminar Datenbanken, ab nächster Woche Raum 2.110,
   Bitte um Aktualisierung im Vorlesungsverzeichnis bis Freitag
   ```
5. **Verbessern:** eine Regel ergänzen lassen, zum Beispiel für Betreffzeilen.

## Musterlösung
`.claude/skills/mail-dekanat/SKILL.md`. Achtung: Wenn Sie Ihren Skill ebenfalls `mail-dekanat` nennen, überschreiben Sie die Musterlösung. Wählen Sie im Zweifel einen eigenen Namen.
