# Aufgabenkarte J: Ein Loop mit /goal

**Ziel:** einen Regelkreis mit ehrlicher Prüfung erleben. **Dauer:** 15 Minuten. **Ausführlich:** Skript, Kapitel 7.6, und `loop-demo/README.md`.

1. `python3 loop-demo/pruefe_zusammenfassung.py` ausführen: nicht bestanden.
2. Die Bedingung aus `loop-demo/ziel.md` in Claude Code eingeben.
3. Beobachten, wie Claude schreibt, prüft und nachbessert.
4. `git diff --stat`: Nur `zusammenfassung.md` darf geändert sein.
5. Zurücksetzen mit `git checkout -- loop-demo/zusammenfassung.md`.
