# Starter-Prompts für eigene Skills

## Allgemein
```text
Lege einen Projekt-Skill namens "<name>" an. Er soll <Aufgabe>.
Fehlende Angaben soll er nachfragen. Nutze die Vorlage vorlagen/skill-vorlage/SKILL.md.
Zeige mir die SKILL.md, bevor du sie speicherst.
```

## Aus einem Beispiel lernen
```text
Hier ist ein Beispiel, wie ich diese Aufgabe gelöst habe: <Beispiel>.
Leite daraus einen Skill ab, der künftig genauso vorgeht.
Zeige mir, welche Regeln du aus dem Beispiel abgeleitet hast.
```

## Beschreibung schärfen
```text
Prüfe die Beschreibung im Kopfbereich des Skills "<name>".
Würdest du ihn bei diesen drei Anfragen automatisch verwenden? <Anfragen>
Schlage eine bessere Beschreibung vor.
```

## Ideen für die Hochschule
- Rückmeldung zu Gliederungen von Abschlussarbeiten nach festem Raster
- Ankündigungen für die Lernplattform aus Terminangaben
- Übungsaufgaben mit Musterlösung und typischem Fehler
- Literatur-Exzerpt nach eigenem Schema
- Mail an Dekanat oder Prüfungsamt (Musterlösung in `.claude/skills/mail-dekanat/`)
