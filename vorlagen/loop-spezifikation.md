# Loop-Spezifikation (Vorlage)

Nach Skript, Kapitel 7.3. Ausfüllen, bevor ein Loop gebaut wird.

| Teil | Frage | Ihre Antwort |
|---|---|---|
| Trigger | Wer oder was startet? Person, Zeitplan, Ereignis | |
| Ziel | prüfbar formuliert, z.B. „pruefe.py endet mit Exit-Code 0“ | |
| Ausführung | welche Skills, welche Rechte, was ist tabu? | |
| Prüfung | welche Stufe (1 deterministisch bis 5 Mensch)? Macher und Prüfer getrennt? | |
| Abbruch | höchstens wie viele Durchläufe, welches Budget? | |
| Endzustände | Erfolg, nichts zu tun, blockiert, festgefahren, Budget erschöpft: was passiert jeweils? | |
| Gedächtnis | wo liegen Plan, Fortschritt, Entscheidungen (Dateien, nicht Chat)? | |

**Goldene Regel:** Ein Loop lohnt sich nur, wenn das Ergebnis eines Durchlaufs die nächste Aktion verändert.
