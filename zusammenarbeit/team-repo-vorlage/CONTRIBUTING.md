# Mitarbeiten: Menschen und Claude-Instanzen

1. **Vor der Arbeit** `git pull`, damit Ihre Claude-Instanz den aktuellen Stand kennt.
2. **Eigener Zweig** pro Aufgabe; parallele Sitzungen in eigenen Worktrees.
3. **Kontext pflegen:** Neue Regeln in die `CLAUDE.md`, Entscheidungen als ADR, wiederkehrende Abläufe als Skill.
4. **Übergeben:** Vor Pausen `/handover` und die Datei nach `docs/uebergaben/` legen.
5. **Prüfen:** Jeder Pull Request wird von einem Menschen freigegeben; eine zweite Claude-Instanz darf vorab prüfen.
6. **Nie** Zugangsdaten oder personenbezogene Daten committen.
