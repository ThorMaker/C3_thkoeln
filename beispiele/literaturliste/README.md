# Beispielprojekt Literaturliste

Kleines Python-Projekt für die Demo „Die erste Aufgabe: ein echter Fehler“ (Skript, Kapitel 2.2) und Übung F (Kapitel 3.7).

Es enthält **zwei absichtliche Fehler**. So sehen Sie sie:

```bash
cd beispiele/literaturliste
python3 -m unittest -v        # Windows: python -m unittest -v
```

Zwei der vier Tests schlagen fehl. Lassen Sie Claude Code die Ursache finden, im Plan-Modus eine Lösung vorschlagen und nach Ihrer Freigabe umsetzen. Die Datei `CLAUDE.md` in diesem Ordner zeigt, wie eine Projekt-Anweisung für einen Unterordner aussieht.
