# Unterprojekt Literaturliste

Diese Datei gilt nur für diesen Ordner. Claude Code liest sie, sobald es hier Dateien öffnet.

- Python 3.10 oder neuer, keine externen Pakete.
- Tests: `python3 -m unittest -v` in diesem Ordner (unter Windows `python -m unittest -v`).
- Sortierung nach DIN 5007-1, Variante 1: ä = a, ö = o, ü = u, ß = ss; Groß- und Kleinschreibung spielt keine Rolle.
- Fehlt das Jahr, wird „o. J.“ ausgegeben.
- Ändere nur `literaturliste.py`. Die Tests beschreiben das gewünschte Verhalten und werden nicht angepasst.
